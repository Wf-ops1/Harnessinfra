# Knowledge Plane Template

Esta pasta contém o template de estrutura de conhecimento do produto.

## Como Usar em um Novo Projeto:
Copie o conteúdo de `knowledge/_template/` para o diretório `knowledge/` na raiz do seu repositório de produto.

### Estrutura:
- `prd.md`: Documento de Requisitos do Produto.
- `domain_model.md`: Modelo do Domínio e Entidades.
- `adrs/`: Architecture Decision Records.
- `specs/`: Especificações executáveis de módulos.
